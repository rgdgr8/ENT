== Known Issues
 * The update of the "gracenote truststore" via Magic-Adapter is kept activated as agreed with Cariad even if the "gracenote truststore" is not integrated on Magic side
   ** Thus always the fallback trustore which is installed as asset of the Metadata-Service App is used
   ** Corresponding errors / warnings might be seen in the trace which must be accepted
 * Please delete the cache of the Metadata-Service App after updating to version >= "1.2.12-MAIN"
   ** This must only be done once to fix an access right issue
   ** This could be done manually by connectiong to the target via ADB or via factory settings
 * GMD-Functionality is not enabled in Service configuration at the OEM-Backend -> Thus it could not be tested at all

== Config
 * The usage of "AudioSource.REMOTE_SUBMIX" has been de-activated as per Cariad request to workaround audio stuttering with active song recognition
   ** The Android bug is known and has already been reported to Google, see https://partnerissuetracker.corp.google.com/issues/390580815
 * In case the End-2-End "Online" connection is not working, parts can be skipped for testing via "Metadata Demo Activity" (Open App -> Tab "Settings Tab") as follows:
   ** "Check Disabled Reasons": disabled
   ** "Network over D-Link": enabled (Hint: An USB2Ethernet D-Link adapter must be connected and activated)
   ** "Online data": enabled
 * The Gracenote Online functionality is available as per Gracenote license file provided per brand
